# Threads - Non Standard

## Metric V Thread Form

![Thread Geometry](../assets/images/line_drawings/threading_dark_mode.png)

| Symbol | Description |
|---|---|
| D | Major diameter of internal thread |
| d | Major diameter of external thread |
| D₂ | Pitch diameter of internal thread |
| d₂ | Pitch diameter of external thread |
| D₁ | Minor diameter of internal thread |
| d₁ | Minor diameter of external thread |
| P | Pitch |
| H | Height of fundamental triangle |

## Example Drawing Note
```text
<Thread Form><Nominal Diameter> x <Pitch> - [Starts] ([lead])
```

Example:
```text
M8.5 x 1 - 2 START (LEAD 2)
```

## Rules of Thumb for 60 Degree Metric Threads
Where D is the nominal diameter, P is the pitch.

| Feature | Rule of thumb |
|---|---|
| Tap Drill (Cutting Tap) | Tap drill ≈ D − P |
| Internal Thread Relief | Relief Ø ≥ D + 0.2 mm, Depth ≈ 1 - 2P |
| External Thread Relief | Relief Ø ≤ D − 1.3P (approx) |
